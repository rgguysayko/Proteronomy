Welcome to the official open-science repository for **Proteronomy**, an independent, substrate-independent scientific discipline devoted to the general laws that govern the relation of before-and-after ($\prec$). 

This framework establishes a formal, axiomatic structure for classifying temporal consistency regimes and analyzing controlled temporal interventions, completely independent of any particular physical, computational, biological, or narrative realization.

## 🗺️ The Four Axiomatic Consistency Regimes

Any coherent temporal structure mapped by this science falls into one of four fundamental categories:

| Regime | Precedence Structure | Cyclicity | Interference Rule | Primary Axiom |
| :--- | :--- | :--- | :--- | :--- |
| **I. Strict Linear Order ($R_L$)** | Total order | Forbidden | Single execution path | Totality & irreflexivity |
| **II. Branching Time ($R_B$)** | Left-linear tree | Forbidden | No cross-branch influence | Left-linearity |
| **III. Closed Loops ($R_C$)** | Cyclic graph | Permitted | Fixed-point constraint | $T(s) = s$ |
| **IV. Multi-Timeline ($R_M$)** | Disjoint parallel | Per timeline | Regulated bridge channels | Boundary mapping |

## 🔬 Core Postulates

Proteronomy builds upon seven fundamental, substrate-independent postulates:
* **P1 (Asymmetry):** In $R_L$, if $e_1 \prec e_2$, then $e_2 \nprec e_1$.
* **P2 (Transitivity):** In $R_L$, if $e_1 \prec e_2$ and $e_2 \prec e_3$, then $e_1 \prec e_3$.
* **P3 (Local Consistency):** No structure may contain immediate contradiction without a balancing mechanism.
* **P4 (Global Consistency under Closure):** Loops are valid if and only if their initial state is a fixed point of the intervention map: $\text{Fix}(T)$.
* **P5 (Branch Isolation):** Interventions in one branch do not alter $\prec$ in another without active channels.
* **P6 (Intervention Cost):** Altering the extension of $\prec$ incurs a measurable structural cost $C(I)$.
* **P7 (Substrate Independence):** Logic and coherence conditions on $\prec$ are structurally prior to physics.

## 🛠️ The Central Open Problem: Transition Rules ($\tau$)

The primary frontier of the discipline lies in formalizing the rules governing transitions between regimes ($\tau(R_i \rightarrow R_j)$) under deliberate interventions ($I$). We invite specialists in **order theory, formal logic, quantum foundations, distributed computer systems, and category theory** to collaborate on calculating:
1. The conditions under which a linear order opens into a branch.
2. The mathematical criteria for forcing a branch to collapse into a self-consistent loop.
3. The absolute resource or informational cost $C(I)$ required to restore consistency after structural shifts.
